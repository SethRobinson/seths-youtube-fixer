Seth’s YouTube Fixer

Power-user controls for YouTube in Safari.

  1. Open Settings → Apps → Safari → Extensions.
  2. Enable Seth’s YouTube Fixer.
  3. Open YouTube in Safari, sign in, and allow the extension on YouTube.

The controls appear below the video. Tap More for settings, comment search, and Forget recent.

For Forget recent, also allow access on My Activity. For comment search, add your YouTube Data API key in the extension settings.

This extension works in Safari. It does not modify the YouTube app. Settings and cached feedback stay in this browser.
